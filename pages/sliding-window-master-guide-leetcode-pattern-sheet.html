1. Fixed Size Sliding Window

Recognition

Use when:

  • window size K is fixed
  • “subarray of size K”
  • “K consecutive elements”
  • fixed-length substring

Core Idea

Add right element. Remove left element. Maintain exact size K.

Template

int i = 0, j = 0;

while (j < n)
{
    add(arr[j]);

    if (j - i + 1 < k)
    {
        j++;
    }
    else if (j - i + 1 == k)
    {
        process();

        remove(arr[i]);
        i++;
        j++;
    }
}

2. Variable Window — Longest Pattern

Recognition

Use when problem asks:

  • longest
  • maximum length
  • at most K
  • largest valid window

Core Idea

Expand aggressively. Shrink only when invalid.

Template

int i = 0;

for (int j = 0; j < n; j++)
{
    add(arr[j]);

    while (invalid)
    {
        remove(arr[i]);
        i++;
    }

    ans = max(ans, j - i + 1);
}

3. Variable Window — Shortest Pattern

Recognition

Use when problem asks:

  • minimum
  • shortest
  • smallest window

Core Idea

Expand until valid. Then shrink as much as possible.

Template

int i = 0;

for (int j = 0; j < n; j++)
{
    add(arr[j]);

    while (valid)
    {
        ans = min(ans, j - i + 1);

        remove(arr[i]);
        i++;
    }
}

4. HashMap / Frequency Sliding Window

Recognition

Use when problem involves:

  • duplicates
  • distinct characters
  • frequencies
  • occurrences
  • counts

Data Structures

  • unordered_map
  • map
  • frequency array
  • unordered_set

Template

unordered_map<char,int> mp;

for (int j = 0; j < n; j++)
{
    mp[s[j]]++;

    while (invalid)
    {
        mp[s[i]]--;

        if (mp[s[i]] == 0)
            mp.erase(s[i]);

        i++;
    }
}

5. Counting Window Pattern

Recognition

Use when asked to:

  • count subarrays
  • count substrings
  • total valid windows

Key Insight

If window [i…j] is valid, then all subarrays ending at j and starting from i to j are valid.

Contribution:

(j - i + 1)

Template

ans += (j - i + 1);

6. The Exactly K Trick

Formula

Exactly(K) = AtMost(K) - AtMost(K-1)

Why It Works

AtMost(K) contains:

0,1,2,…,K

AtMost(K-1) contains:

0,1,2,…,K-1

Subtracting gives exactly K.

7. Monotonic Deque Window

Recognition

Use when problem asks:

  • maximum in every window
  • minimum in every window
  • maintain min/max dynamically

Data Structure

Deque.

Core Idea

Remove useless smaller elements. Front always stores best candidate.

Template

while (!dq.empty() && nums[dq.back()] < nums[i])
    dq.pop_back();

Final Mental Model

Expand right.
Shrink left when invalid.
Record answer at correct moment.

Most sliding window problems are just variations of this same framework.
