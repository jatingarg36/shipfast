1. What is Sliding Window?

Sliding Window is an optimization technique used mainly on linear data structures like arrays and strings.

Instead of recalculating every subarray from scratch, we maintain a moving window and update the answer incrementally.
Arrays Strings Subarrays Substrings Contiguous Optimization

Complexity Reduction

Approach Complexity
Brute Force O(n²) or O(n³)
Sliding Window O(n)

3. Fixed Size Sliding Window

Recognition

  • Subarray of size K
  • K consecutive elements
  • Fixed-length substring

Template

int i = 0, j = 0;

while (j < n)
{
    add(arr[j]);

    if (j - i + 1 < k)
    {
        j++;
    }
    else if (j - i + 1 == k)
    {
        process();

        remove(arr[i]);
        i++;
        j++;
    }
}

4. Variable Size Sliding Window

Expand aggressively. Shrink only when invalid.

Longest Window Pattern

while (j < n)
{
    add(arr[j]);

    while (invalid)
    {
        remove(arr[i]);
        i++;
    }

    ans = max(ans, j - i + 1);

    j++;
}

5. HashMap / Frequency Window

Used when we must track frequencies, duplicates, distinct counts, or occurrences inside the current window.

Core Data Structures

unordered_map map frequency array unordered_set

Template

unordered_map<char,int> mp;

mp[s[j]]++;

while (window invalid)
{
    mp[s[i]]--;

    if (mp[s[i]] == 0)
        mp.erase(s[i]);

    i++;
}

6. Counting Window Pattern

If current window [i...j] is valid, then all subarrays ending at j and starting from i to j are also valid. 
ans += (j - i + 1);

9. Common Mistakes

1. Forgetting to Remove Left Contribution

Always undo frequencies, sums, or counts when shrinking.

2. Infinite Loops

Ensure either left or right pointer moves every iteration.

3. Wrong Validity Condition

Small condition mistakes break the entire window logic.

4. Recording at Wrong Time

Longest and shortest patterns update answers differently.
